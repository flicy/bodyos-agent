# Private Profile Template / 私人档案模板

## 中文

- 内部归属：`fitcrew_user_id`（不要在群聊或模型 envelope 中出现）
- 范围：仅本人单聊
- 来源与确认：记录本人确认时间；未确认内容不得当作事实
- 稳定目标与沟通偏好：`<经本人确认>`
- 敏感健康数据：不要写入此文件，使用 BodyOS 加密数据库与授权 scope

## English

- Internal owner: `fitcrew_user_id` (never expose it in groups or model envelopes)
- Scope: owner DM only
- Provenance and confirmation: record when the owner confirmed it; unconfirmed content is not fact
- Stable goals and communication preferences: `<owner-confirmed>`
- Sensitive health data: never write it to this file; use the encrypted BodyOS database and consent scope
