# Security / 安全

## 中文

不要在公开 Issue、PR、日志或截图中提交真实健康数据、飞书标识、消息正文、私人书籍、设备 token、OAuth 凭据或 `.env`。发现漏洞时请通过 GitHub 私密漏洞报告联系仓库所有者，并提供不含真实数据的最小复现。Owner-only Alpha 不接受外部真实健康数据测试。

## English

Never place real health data, Feishu identifiers, message text, private books, device tokens, OAuth credentials, or `.env` content in public issues, PRs, logs, or screenshots. Use GitHub private vulnerability reporting and provide a minimal reproduction without real data. The owner-only Alpha does not accept external real-health-data testing.
