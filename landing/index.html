核心差异

为什么说它不是客服，是你自己的 Body OS？

客服和健康专家的差别，就在于这四样东西：对你的记忆、对你的理解、专业的知识、还有你自己的数据。FitCrew 四样都有。

🧠

你的记忆

它记得你的每一次打卡、每一个目标、每一点进展，甚至你随口提过的伤病。不是问完就忘的问答机器人——它知道“你上周怎么了”。

🎯

你的偏好

你喜欢什么运动、作息什么样、吃软还是吃硬——建议是为“你”定制的，不是对谁都一样的通用模板。

📚

专家系统

内置运动 / 营养 / 睡眠 / 恢复知识框架，加上持续加入的书籍笔记——像《抗糖革命》、精力管理。健康不止运动，还包括怎么好好吃。

🗄️

你的数据库

开始用的那一刻，就为你初始化专属健康数据库：目标、基线、伤病、习惯。数据属于你、随你成长——这是 FitCrew 一切能力的底座。

核心能力

同一套专家大脑，两种触达方式，互不串味

群里是气氛组与同伴，单聊里是私密顾问。该公开的鼓励进群，该私密的数据只属于你。

入组评估目标拆成微目标每周私聊小结

科学方法，下沉到每次触达

运动 / 营养 / 恢复 / 睡眠知识框架 + 行为科学方法论。

工作原理

拉进群，剩下的交给它

不需要配置复杂的打卡工具。机器人进群的那一刻，陪伴就开始了。

拉进群

把 FitCrew 拉进任意健康群，它自动识别并建立群档案。

定目标

自动发引导消息，让每位成员说出最想达成的健康目标。

每日陪伴

每天一个最小行动打卡，晚间复盘互赞，被 @ 随时专业回应。

每周小结

周日给每位成员单独私聊推送个人周报，只看坚持，不比数字。

方法论

不靠意志力硬扛，靠对的方法

FitCrew 的每一次提醒都遵循同一套行为科学原则——让坚持变得容易。

微习惯

小到不可能失败

把"减脂 5kg"拆成"今天爬一层楼梯"。门槛低，才做得下去。

看行为，不比体重

评分看坚持，不看数字

完成度比体重秤更重要。今天做到了，就值得被看见。

不惩罚

漏答不追责，可跳过

状态不好就降级或跳过，没有压力，只有随时可以重新开始的陪伴。

你的私密数据，
绝不会出现在群里

群与群严格隔离

A 群的消息、数据、成员，绝不出现在 B 群。

群与个人严格隔离

给建议，不做诊断

真实案例

群里正在发生的真实瞬间

不是演示脚本，是 FitCrew 每天在群里真实做的事——以下都来自真实群聊摘录。

🥟

食物热量秒算

「今晚吃的喜家德 12 个饺子」

→ 秒算 500-600 大卡，蛋白质 / 碳水 / 脂肪逐项分析，判定“合格的一餐”。

🩹

伤员康复陪伴

「今天可以练臀腿了，在慢慢康复」

→ 从自重开始、关注两侧对称、练后冰敷，提醒“别急着上重量”。

✈️

出差健康清单

「又要去上海出差了，有什么注意事项？」

→ 口罩、清淡饮食、常备药，还有一句“出差期间不强制打卡”。

💧

喝水目标管理

「太忙了，忙到只有下午才喝水」

→ 设每小时提醒，9:00-20:00 累计追踪 1.8L 目标，到点喊你。
